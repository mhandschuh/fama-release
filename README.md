# Fama

News for Android: the news of your own sources in one calm list, the same event from several sources as one story,
the article's text in the app without ads, and your own rules for what to leave out, with everything they hid listed
and why. No account, no ads, no tracking; it fetches only while it's open.

This repository only holds the installable APKs. Android 11 or newer.

## Install (with automatic updates)

1. Install **Obtainium** from its [releases page](https://github.com/ImranR98/Obtainium/releases)
   (download the `app-arm64-v8a-release.apk`, open it, allow installing from your browser when asked).
2. In Obtainium: **Add App**, paste `https://github.com/mhandschuh/fama-release`, tap **Add**, then **Install**.
   Allow Obtainium to install apps when Android asks.

Obtainium checks for new versions and shows a notification; tap it to update. Your rules and sources stay.
